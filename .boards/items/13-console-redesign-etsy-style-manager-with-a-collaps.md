Feedback on the editor console is still consistently negative. Direction from the owner (2026-11-12):

- Model the layout on Etsy's shop manager: a collapsible sidebar listing every category.
- Controls change with the editing type. Arrange keeps its arrange-style controls; Edit listings shows all of a Listing's content fields.
- Tags are added, removed and edited inline (chips). No separate "add fields to a tag element" step; that is unnecessary.

Applies to every site the console edits. The editor-reach rule still holds: everything visible stays reachable.

Open questions for a design pass: the category list in the sidebar, which types get their own control set, and how the sidebar behaves on phone width.

Chris, 2026-10-01: the Edit site button shows on storyshapedstudios.com, but the editor took about 60s
to load and looked broken while it did.

**Measured 2026-10-01, warm, unauthenticated, from a desktop:** `loader.js` 0.39s, `GET
/api/sites/storyshaped/boot` 0.31s (22 KB), `console/1.2.0/console.js` 0.37s (762 KB). The public half of
opening the editor (`open()` in `src/loader.js`) is fast once warm.

**Unverified theory:** a cold start stacked on the signed-in requests the editor makes after mounting:
a new Lambda container, `poolFor` (`api/lambda.js`) opening the site's Neon project, which may have
suspended, and checking that project's migrations under the advisory lock. Nothing here was measured
cold or signed in.

**Next:** open Manage → API log for the time it happened and look for a long or failed request; time a
cold open (editor idle 10+ minutes) in DevTools Network to see which request holds the 60s.
